# StockPulse - AI-Powered Investment Decision Dashboard

An interactive investment decision dashboard for Teradyne (TER), built for the **Perplexity Computer Stock Pitch Competition 2026**.

## Features

- **Kronos AI Price Forecast**: 12-month Monte Carlo simulation with bear/base/bull confidence bands
- **Model Council**: Independent analysis from 3 frontier AI models (Claude Opus, GPT-5.4, Gemini 3.1 Pro)
- **Management Quotes**: Key CEO quotes from Q4 2025 earnings call
- **Scenario Analysis**: Bear ($220) / Base ($380) / Bull ($520) with detailed assumptions
- **Peer Comparison**: TER vs KLAC, AMAT, ATEYY, ONTO, COHR with scatter plot
- **Insider & Institutional Activity**: 6-month insider transactions + top institutional holders
- **Academic & Market Research**: Scite.ai peer-reviewed citations + Statista market data
- **17 Perplexity Computer capabilities** used in the research workflow

## Tech Stack

- **Frontend**: React + TypeScript + Tailwind CSS + Recharts
- **Build**: Vite
- **AI**: Kronos Foundation Model (AAAI 2026) for price forecasting via Monte Carlo simulation
- **Data**: Perplexity Finance API, Scite.ai, Statista

## Research Methodology

This dashboard was built entirely using Perplexity Computer, showcasing 17 distinct capabilities:
1. Web Search (macro theme discovery)
2. Finance Tools (quotes, financials, segments, estimates, analyst research, earnings transcripts, insider transactions, institutional holders, politician holdings)
3. Scite.ai (peer-reviewed academic literature)
4. Statista (market sizing data)
5. Model Council (3 frontier AI models in parallel)
6. Website Building (this dashboard)
7. PPTX Generation (pitch presentation)
8. Video Editing (ffmpeg for pitch video)
9. Subagent Orchestration (parallel task execution)
